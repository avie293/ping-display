# Ping Display

See the exact ping of every player instead of the vanilla signal bars.

Ping Display replaces the signal bars in the tab list with each player's ping in milliseconds, colored by connection quality. It is **client-side only** and works on any server **without the server needing the mod**. Features include:

- Ping shown as a number in the tab list, with or without `ms`, and the vanilla signal bars available again with one toggle.
- Colors for good, mid, bad, terrible and unknown ping, applied either in steps or as a smooth gradient between the ranges.
- Adjustable ping ranges (by default good below 50 ms, mid below 100 ms and bad below 200 ms).
- Optional ping on player name tags, with a configurable bracket color.
- A custom text for players whose ping is still unknown, and a toggle for the text shadow.

Pre 2.0.0 versions: [Avies Archive](https://avie.cc/archive/)

Bugs and crashes can be reported in the [issue tracker](https://github.com/avie293/avie-issues/issues) by selecting **Ping Display** as the project.
