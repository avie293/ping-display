## Ping Display

See the exact ping of every player instead of the vanilla signal bars. This client-side mod for Fabric, NeoForge and Forge shows the ping in milliseconds and colors it by connection quality.

### Features

- Replace the signal bars in the tab list with the ping as a number, with or without `ms`.
- Choose your own colors for good, mid, bad, terrible, and unknown ping, either in steps or as a smooth gradient.
- Set the ping ranges yourself (default: good below 50 ms, mid below 100 ms, bad below 200 ms).
- Show the ping on player name tags, with a configurable bracket color.
- Set the text shown while a player's ping is still unknown, and toggle the text shadow.

Requires [TabbyLib](https://github.com/avie293/tabbylib/releases) – currently available for download from GitHub only.
